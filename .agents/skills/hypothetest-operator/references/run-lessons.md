# Run lessons

The runner creates a new lessons.md in each evaluation directory during workspace preparation, before reset or workloads. Use the lesson headings in the Architect's [runner template](../../hypothetest-architect/references/evaluation-template.sh), which owns the template text. Preserve existing run-local feedback on recovery; never seed it from repository-wide lessons.

Record assumptions that held or failed, errors and fixes, tool/environment feedback, and follow-up candidates. Entries name what was expected, what occurred, and the supported change. Users may edit the file after execution. Index it under evidence.generated as kind generated, format markdown.
